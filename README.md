# 아쉬베일 연대기

변방 개척지의 끝나지 않는 연대기. 탑다운 픽셀 필드를 걸어다니는 **관계 중심 RPG**다.

**전투도 몬스터 수집도 없다.** 지역에 나가 판정을 굴리고, 자원을 들고 돌아와
마을을 키우고, 함께 걸은 인물과 가까워진다. 문턱을 넘으면 인물 쪽에서 다가와 말을 건다.

안드로이드 세로 화면 전용 웹 앱(PWA). **완전 무서버, 완전 오프라인.**

## 이런 게 있다

- 그리드 4방향 이동, 한 칸 140ms. 마을 · 실내 · 여섯 지역
- 주 단위 시간. 나가든 쉬든 한 주가 지난다
- 1d20 판정 — 대성공 · 성공 · 실패 · 위기
- 마을 건설과 자원 수지, 기근과 붕괴
- 호감 · 우애/연정 트랙 · 고백 (고백은 **인물이** 한다)
- 인물 초상을 기기 안에서만 붙일 수 있다 (IndexedDB, 밖으로 나가지 않는다)
- 연대기 — 지나온 일이 무주어 문어체로 쌓인다
- 음원 파일 없이 합성한 효과음
- 세이브 꾸러미 내보내기 · 불러오기

## 통신하지 않는다

요구사항이다. CDN 참조도, 분석도, 크래시 리포팅도, 외부 API 호출도 없다.
번들에 남은 `http(s)` 문자열은 전부 라이선스 표기와 XML 네임스페이스다.
세이브는 `localStorage`, 인물 이미지는 IndexedDB — 둘 다 기기 밖으로 나가지 않는다.

## 돌려보기

```bash
npm install
npm run dev
```

```bash
npm run build
```

빌드는 타입 검사를 먼저 통과해야 한다.

지역 배치가 제대로 됐는지(표식이 전부 입구에서 걸어 닿는지) 확인하려면:

```bash
npx tsx scripts/check-region.ts
```

## 스택

Vite · React 18 · TypeScript · Tailwind · Phaser 3 · zustand

규칙 로직은 `src/systems/` 의 순수 함수다 — `(state, input, rng) => { state, entries }`.
Phaser 씬은 상태를 **읽기만** 한다. 수치는 전부 `src/data/` 의 상수다.

## 색

세계 32색 + 캐릭터 8색, 모두 `src/data/palette.ts` 에 있다.
지형은 코드로 직접 그린다 (`src/render/terrain.ts`).
