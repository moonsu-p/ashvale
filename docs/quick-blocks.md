# 붙여넣기 4블록

규칙은 `CLAUDE.md`가 자동으로 처리한다. 공통 규칙 블록을 따로 붙일 필요가 없다.
아래 4개를 순서대로, 한 번에 하나씩. 블록이 끝나면 커밋하고 다음으로.

> **더 합쳐도 된다.** 규칙 유지 문제는 `CLAUDE.md`가 해결하므로 4블록은 안전 여유에 가깝다.
> 다만 **블록 1은 반드시 따로** 한다. 걷는 손맛을 확인하기 전에 뒤를 쌓으면 되돌리기 비싸다.
> 합쳐서 진행하다 아래 신호가 보이면 그때 다시 쪼갠다.
>
> - 지시하지 않은 파일을 고치기 시작한다
> - `src/data/content/`의 대사를 "다듬는다"
> - 색을 팔레트 밖에서 가져온다
> - 완료 조건을 보고하지 않고 다음으로 넘어간다

## 준비 (윈도우)

1. **Node.js LTS**(nodejs.org)와 **Git for Windows**(git-scm.com) 설치
2. `ashvale-v2.zip`을 **압축 풀기** → `C:\ashvale`
   윈도우 zip 미리보기 상태로는 클로드 코드가 파일을 못 본다. 반드시 실제로 풀 것
3. 캐릭터 팩 15장을 `C:\ashvale\raw-assets\characters\` 에 넣는다
   PNG가 그 폴더 바로 아래 보여야 한다. `pack\pack` 처럼 겹쳐 있으면 꺼낼 것
4. Claude 앱 → **Code** 탭 → **Local** → **Select folder** → `C:\ashvale`

## 블록 1 — 셋업과 걷기 (M0 + M1)

```
CLAUDE.md 를 먼저 읽어. 그 규칙이 이 프로젝트 전체에 항상 적용돼.

먼저 확인만:
- node --version, git --version 을 확인해서 둘 다 있는지 알려줘. 없으면 어디서 받는지만 말하고 멈춰
- raw-assets/characters/ 에 PNG 15장이 있는지 확인해서 알려줘

그 다음 순서대로:

[1] git 초기화 + .gitignore (node_modules, dist, .env, *.keystore, *.jks 제외.
    raw-assets/ 는 제외하지 마) + .gitattributes 에 "* text=auto eol=lf"
    → "docs: v2 기획서와 콘텐츠 데이터" 로 커밋

[2] docs/game-design-doc.md 의 §0, §4, §14 를 읽고 M0:
    - Vite + React 18 + TS + Tailwind + Phaser 3 + zustand 셋업
    - GameState 타입 전체 (CompanionRecord / PatronRecord 포함)
    - 시드 주입 가능한 RNG
    - StorageAdapter 인터페이스 + WebStorageAdapter (상태=localStorage, 이미지=IndexedDB)
    - 원장(ledger) 저장·불러오기 규칙
    - schemaVersion 마이그레이션 체인 골격
    - PWA 매니페스트 + 서비스 워커 + navigator.storage.persist()
    - 에셋 매니페스트 + 플레이스홀더 렌더러 (?debugAssets=1)
    - 393x852dp 세로 레이아웃 (HUD 40 / 필드 470 / 조작 180)
    - public/fonts/ 자리와 @font-face (폰트 파일은 내가 나중에 넣음)
    완료 조건: 새 게임 → 새로고침 → 복원. 홈 화면 설치되고 오프라인 실행됨
    → 커밋

[3] §5, §6, §12 를 읽고 M1:
    - Phaser 통합 (캔버스 배경 + React UI 오버레이)
    - Tiled 맵 로드. 레이어 규약 ground / deco / collision / objects
      맵 파일이 아직 없으니 임시로 코드에서 생성한 20x18 마을을 쓰고,
      나중에 Tiled JSON으로 교체할 수 있게 로더를 분리해둘 것
    - 캐릭터 4방향 걷기. src/data/characters.ts 의 상수를 그대로 쓸 것
      (16x24, spacing 0, 행 0=아래 1=왼쪽 2=위 3=오른쪽, 프레임 0-1-2-3 순환)
    - 그리드 이동 한 칸 140ms, 입력 큐 1개
    - 정지 상태에서 다른 방향 첫 입력은 방향만 바꾸고 이동하지 않음
    - 충돌은 collision 레이어로 판정 (타일 종류로 판정하지 마)
    - 카메라 추종, 맵 경계에서 정지
    - D패드 + A버튼, 키보드 방향키 + Space/Enter
    - 바라보는 칸에 대상이 있으면 하단 프롬프트 (A — 말 걸기)
    완료 조건: 폰에서 마을을 걸어다닌다. 벽에 막히고 걷는 게 자연스럽다
    → 커밋

각 단계가 끝나면 완료 조건 충족 여부를 보고하고 멈춰.
```

**여기서 멈추고 폰으로 걸어봐.** 손맛이 안 나면 뒤를 쌓아도 살아나지 않는다.
확인할 것: 한 칸 이동 속도(140ms가 답답하거나 빠른지), D패드 위치, 방향 전환이 자연스러운지.

## 블록 2 — 대화와 세계 (M2 + M3 + M4)

```
docs/game-design-doc.md 의 §2, §3, §8, §10, §11, §15 를 읽고 순서대로 해줘.

[M2] 대화 시스템 전체
     - 필드 위에 덮이는 레이어. 필드를 지우지 말고 어둡게 깔 것
     - 인물 이미지 영역(3:4, 화면폭 78%), 아래에서 14px 올라오며 페이드인 280ms
     - 슬롯 폴백: 상위 없으면 하위, 슬롯 0도 없으면 원형 실루엣. 조용히 폴백할 것
     - 이름표 + 대사창, 글자당 26ms 타이핑, A로 즉시 표시 / 다음
     - 선택지 최대 3개 세로. 선택지 상태에서 A는 아무 동작 안 함
     - prefers-reduced-motion 이면 타이핑 없이 즉시
     완료 조건: NPC에게 A → 대화 → 선택 → 복귀
     → 커밋

[M3] 주 엔진 + 자원 + 계절 + 연대기 + 마을 성장
     - 마을 이동은 시간 무소모, 지역 탐사가 1주 (§2)
     - 주 종료 처리는 §3의 8단계 순서 고정
     - 건물 3단계 시각(레벨 1/4/10), 성벽 둘레 링, 시대별 잠긴 영역 해제
     - 계절 틴트. 캐릭터 레이어에는 CHAR_TINT_SCALE(0.5)만 적용
     완료 조건: 건물을 올리면 마을 풍경이 바뀐다
     → 커밋

[M4] 지역 맵 + 사건 노드 + 탐사 판정 + XP/레벨업 + 스킬 + 유물
     - 서술은 content/region-text.ts 사용. 새로 쓰지 마
     - 유물은 content/world-content.ts 의 RELICS
     - 판정은 1d20이 돌아가다 멈추고 보정값이 하나씩 더해지는 연출로 노출
     완료 조건: 판정 계산식이 화면에 단계적으로 보인다
     → 커밋
```

## 블록 3 — 이미지와 관계 (M5 + M6 + M7)

```
docs/game-design-doc.md 의 §7, §9 를 읽고 순서대로 해줘.

[M5] 이미지 업로드 파이프라인 + 슬롯 해금 + 갤러리 + 꾸러미 내보내기/불러오기
     절대 규칙:
     - 원본 참조를 저장하지 마 (content:// URI, File 핸들, 경로 전부 금지).
       선택 즉시 바이트를 읽어 WebP 재인코딩하고 그 Blob만 저장
     - createImageBitmap(file, { imageOrientation: 'from-image' }) 로 EXIF 회전 처리
     - createObjectURL 결과를 저장하지 말고 언마운트 시 revokeObjectURL
     - zip 구조: save.json + images/companion_{id}_slot_{n}.webp + ledger.json
     완료 조건: 이미지 없이도 정상 작동. 내보내기 → 다른 브라우저에서 불러오기 동작
     → 커밋

[M6] 관계 시스템
     - 원형 6종, 대사는 content/companion-dialogue.ts / patron-dialogue.ts 사용
     - 호감 경로 4개: 동행 탐사 / 고향 지역 / 선물 / 대화 사건. 교류 버튼을 만들지 마
     - 다가옴: 문턱을 넘으면 pendingApproach 에 등록되고,
       다음에 마을에 들어설 때 인물이 플레이어 쪽으로 걸어와 자동으로 대화가 열린다
       무시하면 다음 진입 때 재시도, 3회 무시 시 호감 -3과 함께 물러남
     - 대화 사건은 content/dialogue-events.ts. 주사위를 굴리지 마
     - 동행 탐사(주당 1명), 위기 시 부상 4주
     - 말투가 호감 단계에 따라 바뀌는 것을 실제로 반영
     - 의뢰인 신뢰, 세력 평판. 마탑 +5 시 숲의 부족 -2
     완료 조건: 인물이 마을에서 먼저 다가온다
     → 커밋

[M7] 고백 + 트랙 분기 + 경쟁 사건 + 의뢰인 퀘스트 + 인물 생성 흐름 + 교역·선물
     - 고백은 인물이 한다. 플레이어가 고백하는 선택지를 만들지 마
     - 응답 3가지: 수락 / 보류(6주 뒤 재시도, 3회까지) / 거절(우애 고정, 호감 -10)
     - 연인 다수 허용, 질투 페널티 없음. 소개 연쇄는 우애 트랙(맹우 80) 전용
     - 경쟁 사건: 연인 2명 이상 시 8주마다. 범용 6개를 이름·초상만 바꿔 재사용
     - 퀘스트는 동시 1개, 기한 없음, 실패 없음. 완료는 의뢰인과 대화할 때 보고
     - 교역에 주간 한도(시장 레벨 × 30 금화) 필수
     → 커밋
```

**M5 끝나면 직접 확인할 것**
- [ ] 이미지 추가 → **사진첩 원본 삭제** → 게임 내 이미지가 남아 있는가
- [ ] 세로 사진이 눕지 않는가
- [ ] 갤러리 앱에 게임 이미지가 안 보이는가
- [ ] 인물 화면 5분 열어둬도 앱이 무거워지지 않는가

## 블록 4 — 마무리 (M8 + M9 + M10)

```
docs/game-design-doc.md 의 §12, §13, §14 와 docs/ASSETS.md 를 읽고 순서대로 해줘.

[M8] 시대 확장 + 붕괴 + 세계 이벤트 + 온보딩
     - 붕괴 시 연대기·갤러리·업로드 이미지는 100% 보존. 예외 없음
     - 식량 마이너스 주부터 경고 배너, 2주 전 문어체 경고,
       직전 1주에 유물을 팔아 시간을 사는 거래 선택지 1회
     - 붕괴 1회당 시대 임계값 5% 완화
     - 온보딩에 스플래시·로고·인트로 애니메이션 금지
     → 커밋

[M9] 실제 에셋 교체 + 텍스처 아틀라스 + 팔레트 처리
     - scripts/remap-palette.ts 실행 가능하게 정리
     - characters/ 와 illustration/ 은 리맵에서 제외됨을 확인
     - Kenney 시트는 spacing: 1, 캐릭터 팩은 spacing: 0
     - 캐릭터 시트의 투명은 마젠타 알파 0. 알파를 평탄화하지 마
     - 15장 배역 배정은 나에게 후보를 보여주고 확인받을 것
     완료 조건: ?debugAssets=1 에 자홍 외곽선이 남지 않음
     → 커밋

[M10] 애니메이션·성능 예산 + 비통신 검증 + 밸런스 패스
     - 번들에서 http:// https:// 문자열을 검색해 런타임 참조가 없는지 확인하고 보고
     완료 조건: 실기기 60fps, 비행기 모드에서 전 기능 동작, 네트워크 요청 0
     → 커밋
```
